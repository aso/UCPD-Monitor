# Client Workspace Notes

This directory contains the React + Vite frontend for UCPD-Monitor.

## Scope

- Main UI components (Message Table, Topology View, Measure Panel)
- USB PD parser integration for table/topology rendering
- WebSocket client state management through Zustand

## Scripts

- `npm run dev`: start Vite dev server
- `npm run build`: build production assets
- `npm run preview`: preview built assets

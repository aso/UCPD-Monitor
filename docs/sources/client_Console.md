# client/src/components/Console.jsx

## 役割
アプリケーションのイベント、エラー、警告のリアルタイムログを表示する、スクロール可能な UI コンポーネントです。

## 主な責務
- **ログの描画**: `appStore` からの `consoleLogs` 配列を反復処理し、各ログエントリを個別の行として描画します。
- **視覚的フィードバック**: ログメッセージの内容に基づいて異なる CSS クラス（`lineError`、`lineWarn`、`line`）を適用します。
- **自動スクロール**: 新しいログエントリが追加されるたびに、ログビューの最下部へ自動的にスクロールし、最新の情報が常に表示されるようにします。
- **ログ管理**: ユーザーがログ履歴を手動で消去できるように「クリア」ボタンを提供します。

## 主な機能
- **スムーズスクロール**: 自動スクロール時の洗練されたユーザー体験のために `behavior: 'smooth'` を使用します。
- **セマンティックなスタイリング**: CSS モジュールを使用して、エラー、警告、標準ログレベルを視覚的に区別します。

## 3.2.7 時点の要点
- Console パネルの表示状態は Measure パネルと連動しません（独立トグル）。

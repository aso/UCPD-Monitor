# client/src/components/MeasurePanel.jsx

## 役割
ハードウェアから受信したリアルタイムの電圧 (VBUS) および電流 (IBUS) 測定データを表示する UI コンポーネントです。

## 主な責務
- **ライブデータ表示**: 最も最近の測定値（VBUS はボルト、IBUS は mA）を目立つ読み取りストリップに表示します。
- **測定制御**: ハードウェアからの周期的な測定ストリームを制御するための「開始」および「停止」ボタンを提供します。
- **データ可視化**: 対応するタイムスタンプとともに、最近の測定サンプルの一覧を表示します。
- **フォーマット**: 生のミリボルト (mV) およびミリアンペア (mA) の値を人間が読みやすい形式（例：「15.000 V」）に変換します。

## 主な機能
- **プロトコル統合**: ネストされた VBUS および IBUS データを含む `0x2C` (測定) TLV フレームタイプを処理するために特別に設計されています。
- **状態駆動**: `useAppStore` を使用して、測定サンプル履歴と実行状態にアクセスします。
- **ハードウェアとの連携**: 親コンポーネントから渡される `sendMessage` 関数を使用して、WebSocket 経由でサーバーに制御コマンドを送信します。

## 主なロジック
- **`fmtV(mv)` / `fmtA(ma)`**: 一貫した単位フォーマットのためのユーティリティ関数。
- **`handleStart` / `handleStop`**: 測定ストリームを開始または終了するためにバックエンドに WebSocket メッセージをトリガーします。

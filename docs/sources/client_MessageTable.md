# client/src/components/MessageTable.jsx

## 役割
デコードされたすべての USB-PD メッセージとイベントの履歴を表示する、高性能な仮想化テーブルコンポーネントです。

## 主な責務
- **仮想化レンダリング**: `@tanstack/react-virtual` を使用して、UI パフォーマンスを低下させることなく数千行のメッセージ行を効率的に描画します。
- **データデコード**: 各メッセージフレーム内の複雑なデータオブジェクト（PDO、RDO）を `pd_parser.ts` を利用してデコードします。
- **視覚的エンコーディング**:
    - **方向別カラーリング**: メッセージの方向（例：Source $\to$ Sink は赤、Sink $\to$ Source は青）に基づいて行に色を付けます。
    - **タイプバッジ**: 特殊なバッジ（例：`PDO_BADGE`）を使用して、異なるメッセージタイプを視覚的に区別します。
    - **SOP 品質**: SOP が SOP、SOP'、SOP'' のいずれであるかに基づいて SOP インジケーターに色を付けます。
- **タイムスタンプ変換**: 生のファームウェアティックを、アンカーを使用して人間が読みやすい実時間（壁時計時間）または起動からの経過時間に変換します。

## 主な機能
- **高性能**: ウィンドウ化/仮想化を使用して大規模なデータセットに最適化されています。
- **リッチな情報**: 電圧、電流、機能フラグを含む RDO および PDO の詳細な要約を表示します。

- **セマンティック UI**: カラーコード化されたラベルとアイコンを使用して、複雑な USB-PD プロトコルをひと目で監視しやすくします。

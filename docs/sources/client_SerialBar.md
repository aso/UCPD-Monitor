# client/src/components/SerialBar.jsx

## 役割
シリアルポートの選択とハードウェアへの接続を管理するためのツールバーウィジェットです。

## 主な責務
- **ポート検出**: WebSocket メッセージ（`PORT_LIST`）から動的に更新される利用可能なシリアルポートのリストを表示します。
- **接続制御**: シリアル通信セッションを開始または終了するために「接続」および「切断」ボタンを提供します。
- **デバイス識別**: 既知の STMicroelectronics 開発ボード（例：`0483:374B` $\to$ `STM32G071B-DISCO`）に対してフレンドリーな名前を表示するためのルックアップテーブルを使用します。
- **コマンドディスパッチ**: WebSocket 経由でバックエンドに `SERIAL_CONNECT` / `SERIAL_DISCONNECT` / `GET_PORT_LIST` コマンドを送信します。

## 主な機能
- **手動接続**: 誤ってハードウェアに干渉するのを防ぐため、自動接続は行いません。ユーザーが明示的に接続を押す必要があります。
- **スマート選択**: ポートリストが変更されたときに、以前使用されたポートを自動的に選択します。
- **プロトコルトリガー**: CPD ストリーミングモードをトリガーするために、特定のボーレート（`921600`）を「マジックナンバー」として使用します。

# client/src/components/TopologyView.jsx

## 役割
USB-PD 接続トポロジー（Source、Sink、eMarker）の現在の状態を表す、ハイレベルな視覚化コンポーネントです。

## 主な責務
- **トポロジーの視覚化**: 接続チェーンのグラフィカルな表現（例：Source $\to$ Cable $\to$ eMarker $\to$ Sink）を描画します。
- **機能の表示**: PDO、RDO、EPR サポートなどの接続されたデバイスのアクティブな機能を表示します。
- **動的更新**: `appStore` のトポロジー状態が変更されたとき（例：新しい接続またはロールスワップ時）に自動的に再レンダリングします。
- **ベンダー識別**: 接続された USB デバイスのベンダーID (VID) に基づいて、ルックアップテーブル (`USB_VID_SS`) を使用して製造元を識別します。

## 主な機能
- **インタラクティブ要素**: `EPR`、`DRD`、`DRP` などのプロトコル機能のバッジを表示します。
- **プロトコル固有のデータ**: 特殊なメタデータを使用して、Power Data Object (PDO) および Request Data Object (RDO) の詳細情報を描画します。
- **接続ステータス**: ケーブルが接続されているか、接続がアクティブであるかを視覚的に示します。

## 主要なロジック
- **VID 検索**: 生の USB ベンダーIDを人間が読める製造元名にマッピングします（例：`0x0483` $\to$ `STMicroelectronics`）。
- **状態駆動レンダリング**: `appStore` から `INITIAL_TOPOLOGY` とその更新を直接消費します。

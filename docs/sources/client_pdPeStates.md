# client/src/data/pdPeStates.ts

## 役割
USB-PD の電源状態（Power State）に関する定数および状態遷移の定義を保持します。

## 主な責務
- **状態定義**: USB-PD プロトコルで定義される各種電源状態（例：SOP, SOP', SOP''）の定数を定義します。
- **状態遷移ロジック**: 状態遷移のルールや、特定のイベントが発生した際のアプリケーションの挙動を定義するための基盤を提供します。

## 主な機能
- **プロトコル準拠**: USB-PD Rev 3.2 の電源状態定義に準拠します。
- **コードの整理**: 状態関連のロジックをデータ層に分離し、アプリケーションの保守性を高めます。

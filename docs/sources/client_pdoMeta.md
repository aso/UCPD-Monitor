# client/src/data/pdoMeta.ts

## 役割
USB-PD Power Data Object (PDO) タイプとその視覚的表現の単一情報源として機能する、設定およびメタデータモジュールです。

## 主な責務
- **メタデータの定義**: 各 PDO タイプについて、以下のプロパティを定義します。
    - `key`: 内部文字列識別子（`pd_types.ts` と一致）。
    - `badge`: `MessageTable` や `TopologyView` のような UI コンポーネントで使用される短いテキストラベル。
    - `lamp`: 「ランプストリップ」の視覚化で使用される非常に短いラベル。
    / `color`: 視覚的な区別に使用されるアクセントカラー（16進数）。
- **視覚的一貫性**: アプリケーション全体で同じ色とラベルが使用されることを保証します（例：凡例、トポロジービュー、メッセージテーブル）。

## 主要なデータ構造
- `PDO_TYPE_META`: サポートされているすべての PDO タイプ（Fixed, Battery, Variable, PPS, EPR-AVS など）の配列。
- `PDO_COLOR`: PDO タイプキーをその16進数カラーにマッピングするルックアップテーブル。
- `PDO_BADGE`: PDO タイプキーをそのバッジラベルにマッピングするルックアップテーブル。

## サポートされる PDO タイプ
- **Fixed**: 標準の固定電圧/電流。
- **Battery**: バッテリー固有の電力プロファイル。
- **Variable**: 可変電圧/電流プロファイル。
- **PPS (APDO_PPS)**: プログラマブル電源供給。
- **EPR-AVS / SPR-AVS**: 拡張/標準電力範囲 AVS。

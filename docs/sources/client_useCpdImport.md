# client/src/hooks/useCpdImport.js

## 役割
アプリケーションの状態に `.cpd` バイナリログファイルをインポートおよび処理するための機能を提供するカスタム React フックです。

## 主な責務
- **ファイル取り込み**: Web ベースのファイルアップロード（`File` オブジェクト経由）と Electron ベースのファイルパスインポートの両方を処理します。
- **バイナリ結合**: 複数のファイルが選択された場合、それらを `ArrayBuffer` として読み込み、アップロード前に単一の連続したバイトストリームにマージします。
- **サーバーサイド統合**: バックエンドサーバーの `/api/import-cpd` および `/api/import-cpd-by-path` エンドポイントと通信し、バイナリデータを処理します。
- **進捗追跡**: 現在のインポートステータス（ローディング、ファイル名、進捗など）をグローバルな `appStore` に更新します。
- **ロギング**: インポートイベントとエラーをアプリケーションの内部ログに記録します。

## 主要なメソッド
- `importFiles(files)`: 
    - `FileList` または `File[]` を受け取ります。
    - バッファをマージします。
    - `application/octet-stream` コンテンツで `POST` リクエストを送信します。
- `_importByPaths(filePaths)`: 
    - Electron 環境専用です。
    - 直接読み取りのために絶対ファイルパスのリストをサーバーに送信します。

## 主な機能
- **並行処理**: `Promise.all` を使用して複数のファイルを並行して読み込みます。
- **堅牢性**: フェッチプロセス中のエラーを処理し、アプリケーションログを通じて報告します。

# electron/main.js

## 役割
Electron アプリケーションのメインプロセスです。アプリケーションのライフサイクル、ウィンドウ作成、およびシステムレベルの統合を管理します。

## 主な責務
- **ウィンドウ管理**: `BrowserWindow`（サイズ、タイトル、Web プリファレンス）を作成および設定します。
- **バックエンドのオーケストレーション**: 組み込み Node.js サーバー (`server/index.js`) の起動とシャットダウンを制御します。
- **IPC (プロセス間通信)**: レンダラープロセス（UI）とメインプロセス間の通信のためのハンドラを実装します。
- **システム統合**:
    - `.cpd` ファイルを開くためのネイティブファイルダイアログを提供します。
        - `electron-updater` を介したアプリケーションアップデートを処理します。
- **環境設定**: `UCPD_PORT` や `UCPD_USER_DATA` のような必須環境変数を設定します。

## 主要な IPC ハンドラ
- `open-file-dialog`: 1つまたは複数の `.cpd` ファイルを選択するためのネイティブダイアログを開きます。
- `open-file-dialog-free`: デフォルトパスなしでネイティブダイアログを開きます。

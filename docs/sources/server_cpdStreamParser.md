# server/cpdStreamParser.js

## 役割
シリアルポートからの生のバイトストリームを、完全で構造化された CPD (USB-PD Monitor) フレームに解析するために設計された Node.js の `Transform` ストリームです。

## 主な責務
- **ストリーム処理**: 受信したバイトチャンクを内部バッファに蓄積します。
- **フレーム同期**: 受信ストリームをスキャンし、`FD FD FD FD` の同期パターンを特定してフレームの開始を識別します。
- **TLV 解析**: フレームタグ、長さ、ペイロードを抽出するために、タグ-長さ-値 (TLV) 解析ロジックを実装します。
- **CPD フレームの識別**: `CPD_TAG` (0x32) を持つフレームを特定し、完全な `Buffer` オブジェクトとしてエミットします。
- **バッファ管理**: チャンク境界をまたぐ部分的なフレームを、最近のバイトの小さなバッファを維持することで処理します。

## 主要なロジック
- **同期検出**: `_findSync()` を使用してフレームの開始位置を特定します。
- **フレーム境界検出**: TLV ヘッダーの `Length` フィールドに基づいて期待されるフレーム長を計算し、バッファに十分なバイトが利用可能になるまで待ちます。
- **イベントエミッション**: 完全で有効な CPD フレームが識別されるたびに `'frame'` イベントをエミットします。

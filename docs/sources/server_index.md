# server/index.js

## 役割
バックエンドサーバーのエントリポイントです。Express アプリケーションと WebSocket サーバーを設定し、Electron フロントエンドとハードウェア（USB-PD デバイス）間の通信を円滑にします。

## 主な責務
- **サーバーの初期化**: 設定可能なポート（デフォルト: 57321）で Express サーバーを起動します。
- **WebSocket サーバー**: クライアントへのリアルタイムデータストリーミング（例：USB-PD メッセージ、ステータス更新）のための WebSocket インターフェースを提供します。
- **プロセス管理**: 特定の TCP ポートを占有している OS プロセスを識別するためのユーティリティ関数を含みます（ポート競合の防止に役立ちます）。
- **ロギング**: デバッグ目的で「不明」またはデコードされていないパケットの YAML 形式のログを維持します。
- **統合**: `serialport` ストリーム（`cpdStreamParser.js` 経由）と Web ベースの UI との橋渡し役を果たします。

## 主要な関数
- `getPortOwnerProcessName(port)`: `netstat` (Windows) または `lsof` (Unix) を使用して、ポートを占有しているプロセス名を見つけます。
- `getLogsDir()`: セッションログを保存するディレクトリを解決します。
- `recordToYaml(rec, capturedAt)`: 不明なパケットレコードを後で分析するための構造化された YAML 形式にシリアル化します。
